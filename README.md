## 🧠 The Philosophy

Most creators use Notion to store data. We use it to execute software.

**Bloom Flow** is a project execution model that abandons traditional folders and blank pages. It doesn't just hold your scripts—it actively accelerates your output. By piloting Notion's Formula 2.0 to its ceiling and bridging it with self-contained web applications, we've built an aerodynamic sandbox where deep work happens and assets route themselves.

## 📐 Ecosystem Architecture: The 3 Pillars

This repository contains the frontend of the Bloom Flow ecosystem. The architecture is divided into three distinct layers:

### 1. The Matrix (Relational Architecture)
A zero-friction, self-relating database model built natively in Notion. It acts as the primary execution environment, replacing scattered folders with a unified **Scene Orchestrator** for mapping visual and audio cues on a strict timeline.

### 2. The Logic (Formula 2.0 Telemetry)
We embedded an **Active Coaching HUD** directly into the matrix. This dynamic algorithm reads your inputs in real-time, flags pacing bottlenecks, measures project health, and gives you a visual "Clear for Flight" signal when your assets are locked.

*(The underlying Formula 2.0 expressions are proprietary and ship only in the managed tiers.)*

### 3. The Flight Manual (Serverless SaaS UI)
A custom, self-contained web application served via **Google Apps Script** into Notion. It features:
*   **Google Material UI:** A crisp, high-contrast 2x2 grid for rapid Q&A.
*   **Aura Voice Guide:** A Base64 audio player for frictionless system onboarding.
*   **Smart Return Navigation:** Context-aware JS routing (`document.referrer`) that drops users right back into their active episode matrix.

*(Note: the headless **Python Automation Engine** — zero-touch handoffs and external asset routing — is available in the fully managed Pro tier.)*

## 🚀 Quick Start & Deployment

Want to deploy the Episode Engine into your own workspace? Here's the pre-flight checklist:

### 1. Clone the Notion Matrix
Duplicate the core OS database into your Notion workspace:
👉 **[Get the Notion Matrix Here](YOUR_NOTION_TEMPLATE_LINK_HERE)**

### 2. Deploy the Serverless Flight Manual
Deploy this repository's code to your own Google Account to run the UI inside Notion:
1. Go to [script.google.com](https://script.google.com/) and create a **New Project**.
2. Copy `gas/Code.gs` and `gas/Index.html` from `bloom-flow/Episode Engine Flight Manual/` into your GAS project.
3. Add your GA4 Measurement ID in the `<head>` of `Index.html` for traffic telemetry.
4. Click **Deploy > New Deployment**.
5. Select **Web App**, set *Execute as* to **Me**, and *Who has access* to **Anyone**. Click **Deploy**.
6. Copy the resulting Web App URL, type `/embed` in your Notion dashboard, and paste the link.
